# Tech Game

Tech Game — браузерная командная викторина в формате «Своей игры». Python-сервер управляет состоянием матча и вопросами, а TypeScript-интерфейс отображает игровые экраны и обменивается с сервером сообщениями через WebSocket.

## Возможности

- создание команд и подсчёт очков;
- автоматическая смена активной команды;
- выбор категорий, вопросов и стоимости вопроса;
- категории с уровнями сложности и категории с подкатегориями;
- проверка ответа и изменение счёта команды;
- отметка использованных вопросов и завершённых категорий;
- сохранение незавершённой игры и продолжение после повторного запуска;
- досрочное завершение игры и итоговый рейтинг команд;
- подключение браузера с другого устройства в локальной сети.

## Технологии

- Python 3.10+
- TypeScript 5
- HTML и CSS
- WebSocket (`websockets`)
- JSON
- Node.js, npm и BrowserSync
- PyInstaller

## Как устроен проект

Backend хранит команды, очки, выбранную категорию, текущий вопрос и использованные вопросы. Вопросы загружаются из JSON-файлов при запуске. Состояние незавершённой игры сохраняется в реестре текущего пользователя Windows.

Frontend состоит из отдельных экранов: приветствие, создание команд, выбор категории, игровое поле, вопрос, текущий счёт и итоговые результаты. Клиент вызывает методы backend через WebSocket и получает JSON-ответы.

## Установка

Актуальная версия рассчитана на Windows: состояние игры сохраняется в реестре текущего пользователя.

### Backend

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r game_engine\requirements.txt
```

### Frontend

```powershell
cd web_ui
npm install
```

## Запуск для разработки

В первом терминале из корневой папки проекта:

```powershell
python run_server.py
```

WebSocket-сервер по умолчанию слушает порт `8001` на всех сетевых интерфейсах.

Во втором терминале:

```powershell
cd web_ui
npm run dev
```

BrowserSync компилирует TypeScript, открывает интерфейс на `http://localhost:5501` и следит за изменениями frontend-файлов.

Для остановки процессов frontend:

```powershell
npm run kill
```

## Подключение из локальной сети

Сервер и веб-интерфейс используют адрес компьютера, на котором запущен проект. Другие устройства в той же сети могут открыть адрес, который BrowserSync выводит как `External`.

Если подключение не устанавливается, необходимо разрешить входящие соединения для портов `5501` и `8001` в настройках брандмауэра.

## Настройка backend

Хост и порт задаются переменными окружения:

```powershell
$env:GAME_HOST = "0.0.0.0"
$env:GAME_PORT = "8001"
python run_server.py
```

## Формат вопросов

Вопросы находятся в `game_engine/resources/game_questions`.

Обычная категория содержит девять файлов с именами от `100.json` до `900.json`. Категория с подкатегориями содержит вложенные папки; в каждой из них находится по три вопроса.

```json
{
  "title": "Какова временная сложность бинарного поиска?",
  "variants": ["O(n)", "O(log n)", "O(n²)", "O(1)"],
  "correct_answer": "O(log n)"
}
```

Стоимость вопроса определяется именем файла.

## Сохранение игры

Сохраняются:

- названия и очки команд;
- индекс активной команды;
- выбранная категория;
- использованные вопросы.

В Windows состояние хранится в `HKEY_CURRENT_USER\SOFTWARE\TechGame` в значении `game_state`.

## Сборка для Windows

Установите PyInstaller и подготовьте комплект (frontend будет скомпилирован автоматически):

```powershell
pip install pyinstaller
.\bundle.bat
```

Backend будет собран в `dist/tech-game/tech-game.exe`, а frontend скопирован в `dist/web_ui`.

В папке `dist` создаются два сценария запуска:

- `run-game-server.bat` — запуск backend;
- `run-http-server.bat` — запуск HTTP-сервера для frontend на порту `5501`.

Для `run-http-server.bat` требуется установленный Python.
