# Game Engine

Python-бэкенд проекта Tech Game содержит игровую логику, загружает вопросы и обслуживает браузерный клиент через WebSocket.

## Основные модули

- `game.py` — команды, очки, очередность ходов, категории, ответы и состояние игры;
- `category_questions_controller.py` — чтение JSON-файлов, категории, подкатегории и использованные вопросы;
- `server.py` — асинхронный WebSocket-сервер;
- `transport.py` — разбор запросов и формирование JSON-ответов;
- `app.py` — управление циклом событий;
- `main.py` — настройка и запуск приложения;
- `resources/game_questions` — набор вопросов.

## Установка зависимостей

Из корневой папки проекта:

```powershell
pip install -r game_engine\requirements.txt
```

## Запуск

```powershell
python run_server.py
```

Или как Python-модуль:

```powershell
python -m game_engine.main
```

По умолчанию сервер слушает `0.0.0.0:8001`. Значения можно изменить переменными `GAME_HOST` и `GAME_PORT`.

## Формат сообщений

Запрос клиента:

```json
{
  "id": 1,
  "method": "get_category_list",
  "args": []
}
```

Успешный ответ:

```json
{
  "id": 1,
  "result": ["Алгоритмы и структуры данных"],
  "error": null
}
```

Ответ при ошибке:

```json
{
  "id": 1,
  "result": null,
  "error": "Method not found: unknown_method"
}
```

## Хранение вопросов

Каждый вопрос хранится в отдельном JSON-файле:

```json
{
  "title": "Что такое хеш-таблица?",
  "variants": [
    "Структура данных для хранения пар ключ-значение",
    "Отсортированный список",
    "Двусвязная очередь",
    "Бинарное дерево"
  ],
  "correct_answer": "Структура данных для хранения пар ключ-значение"
}
```

Стоимость вопроса берётся из имени файла. Контроллер обычной категории ожидает девять файлов, а контроллер подкатегорий — по три файла в каждой вложенной папке.

## Состояние игры

Класс `Game` сохраняет команды, очки, текущий ход, выбранную категорию и использованные вопросы. В актуальной Windows-версии состояние хранится в реестре пользователя по ключу `HKEY_CURRENT_USER\SOFTWARE\TechGame`.

Подробные инструкции по запуску веб-интерфейса и сборке приложения находятся в корневом `README.md`.
