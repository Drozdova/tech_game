# Game Engine

`game_engine` — backend Tech Game. Он загружает вопросы, хранит состояние матча, применяет игровые правила и обслуживает WebSocket-запросы frontend.

## Модули

- `game.py` — команды, очки, очередность ходов, выбранная категория, проверка ответов и сохранение игры;
- `category_questions_controller.py` — чтение вопросов, обычные категории и категории с подкатегориями;
- `transport.py` — разбор JSON-запроса, вызов метода игры и формирование ответа;
- `server.py` — WebSocket-соединения;
- `app.py` — цикл событий;
- `main.py` — создание `Game` и `GameServer`;
- `resources/game_questions` — данные вопросов.

## Игровая модель

Класс `Game` управляет следующими данными:

- список команд и их очки;
- активная команда;
- доступные категории;
- выбранная категория и вопрос;
- использованные вопросы;
- состояние завершения игры.

`CategoryQuestionsController` работает с категорией из девяти вопросов. `SubcategoriesQuestionController` расширяет эту модель для категорий, разделённых на подкатегории по три вопроса.

## Запуск

Из корневой папки проекта:

```powershell
pip install -r game_engine\requirements.txt
python run_server.py
```

Другой вариант:

```powershell
python -m game_engine.main
```

Значения по умолчанию:

- `GAME_HOST=0.0.0.0`
- `GAME_PORT=8001`

## WebSocket API

Frontend отправляет сообщение с идентификатором, названием метода и аргументами:

```json
{
  "id": 1,
  "method": "get_category_list",
  "args": []
}
```

Успешный ответ:

```json
{
  "id": 1,
  "result": ["Алгоритмы и структуры данных"],
  "error": null
}
```

Ответ с ошибкой:

```json
{
  "id": 1,
  "result": null,
  "error": "Method not found: unknown_method"
}
```

Объекты, у которых определён метод `to_dict`, преобразуются в JSON-совместимый словарь перед отправкой клиенту.

## Работа с вопросами

Контроллер читает JSON-файлы и создаёт объекты `QuestionInfo` со следующими полями:

- текст вопроса;
- стоимость;
- правильный ответ;
- варианты ответа;
- признак использования.

Стоимость берётся из имени файла. При загрузке проверяются количество файлов и отсутствие повторяющихся текстов вопросов.

## Сохранение состояния

После изменения команд, хода, категории или вопроса `Game` сохраняет состояние в реестре Windows:

```text
HKEY_CURRENT_USER\SOFTWARE\TechGame
```

В строковом значении `game_state` хранится JSON с командами, очками, активной командой, выбранной категорией и использованными вопросами.

Метод `clear_saved_state` удаляет сохранение при начале новой игры.
