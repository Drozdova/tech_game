# 🎮 Добро пожаловать в твою игровую песочницу!

Привет! 👋 Этот проект создан специально для тебя, чтобы изучение Python было интереснее и веселее. Здесь ты можешь создать свою собственную игру-викторину!

## 📚 Что это за проект?

Проект состоит из **двух частей**:

1. **Backend (Python)** — это мозг игры. Здесь хранятся вопросы, правильные ответы, счет команд. Именно с этой частью ты будешь работать в первую очередь!
2. **Frontend (HTML/CSS/JavaScript)** — это красивая обертка, которая показывает игру в браузере. Минимальная версия уже готова, и к ней можно вернуться позже, когда захочется что-то изменить во внешнем виде.

## 🚀 Как все запустить?

### Шаг 1: Открой Workspace

**Что такое Workspace?**  
Workspace (рабочее пространство) — это способ работать с несколькими проектами одновременно в одном окне Cursor. У нас как раз два независимых проекта: backend на Python и frontend на JavaScript. Workspace позволяет видеть их оба и легко переключаться между ними.

**Как открыть:**
1. В Cursor нажми `File` → `Open Workspace from File...`
2. Найди и выбери файл `tech-game.code-workspace` (он находится в корневой папке проекта)
3. Или просто найди этот workspace в списке недавних — он там будет отображаться

### Шаг 2: Установи зависимости (только первый раз)

**Для Python (Backend):**
1. Открой терминал в Cursor (Terminal → New Terminal)
2. Убедись, что ты в папке `game_engine`
3. Выполни команду:
```bash
pip install -r requirements.txt
```

**Для Frontend:**
1. Открой второй терминал (Terminal → New Terminal)
2. Перейди в папку `web_ui`:
```bash
cd ../web_ui
```
3. Установи зависимости:
```bash
npm install
```

### Шаг 3: Запусти Frontend сервер (один раз)

Frontend сервер нужно запустить только один раз — он будет работать в фоне и автоматически обновлять страницу при изменениях.

**Как запустить (выбери удобный способ):**

**Способ 1: Через командную палитру (проще)**
1. Нажми `Ctrl+Shift+P` (откроется командная палитра)
2. Начни вводить `npm` 
3. Выбери команду **"npm: Run Script"**
4. В списке найди и выбери **"Frontend (typescript): dev"** (или просто **"dev"**)
5. Откроется терминал, где ты увидишь сообщение:
   ```
   Local: http://localhost:5500
   ```
6. Браузер откроется автоматически! 🎉

**Способ 2: Через терминал**
1. Открой терминал (`Ctrl+` `)
2. Перейди в папку `web_ui`:
   ```bash
   cd web_ui
   ```
3. Запусти команду:
   ```bash
   npm run dev
   ```

**Важно:** Этот терминал должен продолжать работать! Не закрывай его — frontend сервер следит за изменениями в файлах и автоматически обновляет страницу в браузере.

### Шаг 4: Запусти Python сервер

Теперь запусти Python backend. Это можно сделать двумя способами:

**Способ 1: Через VS Code (удобнее для отладки)**
1. Убедись, что ты в папке `game_engine` (переключись на неё в боковой панели)
2. Нажми `F5` (или найди вкладку **Debug** слева и нажми зеленую кнопку ▶️)
3. Выбери конфигурацию:
   - **🐛 Python: Debug** — с возможностью ставить точки остановки (breakpoints)
   - **▶️ Python: Run (No Debug)** — быстрый запуск без отладки (или нажми `Ctrl+F5`)

**Способ 2: Через терминал**
```bash
cd game_engine
python -m game_engine.main
```

### Шаг 5: Вноси изменения и смотри результат

**Важно понимать, как работает обновление:**

Когда ты изменяешь код и сохраняешь файл (`Ctrl+S`), происходит следующее:

- ✅ **TypeScript/HTML/CSS изменения** → браузер обновляется **автоматически**
  - Просто сохрани файл, и через секунду увидишь изменения в браузере
  - Ничего перезапускать не нужно!

- ⚠️ **Python изменения** → нужно **перезапустить Python сервер**:
  1. Сохрани файл (`Ctrl+S`)
  2. Веб-страница обновится автоматически (это нормально, не пугайся)
  3. НО! Чтобы изменения в Python **действительно заработали**, нужно:
     - Нажми `Shift+F5` (или красную квадратную кнопку ⏹️ Stop вверху)
     - Снова нажми `F5` (или зеленую кнопку ▶️ Play)
     - Браузер автоматически переподключится к новому серверу

**Почему так?**  
Python — это серверный язык. Когда ты меняешь код, старая версия программы продолжает работать в памяти. Чтобы применить изменения, нужно остановить старую версию и запустить новую.

**Совет:** Frontend сервер можно оставить работать весь день — перезапускать нужно только Python!

## 🎯 С чего начать программировать?

### Твоя задача — создать настоящую игру!

Сейчас в проекте есть файл `dummy_game.py` — это "пустышка", которая просто возвращает случайные данные. Твоя цель — создать настоящую игру с вопросами, ответами и подсчетом очков!

### Основные файлы, с которыми ты будешь работать:

1. **`game.py`** — это "контракт" (интерфейс), который описывает, какие методы должны быть в твоей игре:
   - `list_teams()` — список команд
   - `get_team_score(team_name)` — получить счет команды
   - `list_questions()` — список всех вопросов
   - `get_variants_for_question(question_index)` — варианты ответов для вопроса
   - `submit_answer(question_id, answer)` — проверить ответ

2. **`dummy_game.py`** — пример простой реализации. Можешь использовать его как шаблон!

3. **`main.py`** — точка входа в программу. Здесь запускается сервер и подключается твоя игра.

### Идеи для начала:

1. **Создай свой класс игры** (например, `MyQuizGame`) на основе `DummyGame`
2. **Добавь настоящие вопросы** — создай список словарей с вопросами и ответами
3. **Реализуй подсчет очков** — когда команда отвечает правильно, добавляй ей очки
4. **Добавь разные категории вопросов** — история, наука, спорт и т.д.

### Пример простой структуры данных для вопросов:

```python
questions = [
    {
        "question": "Какой язык программирования ты сейчас изучаешь?",
        "variants": ["Python", "JavaScript", "Java", "C++"],
        "correct": "Python",
        "points": 10
    },
    {
        "question": "Сколько будет 2 + 2?",
        "variants": ["3", "4", "5", "22"],
        "correct": "4",
        "points": 5
    }
]
```

## 🆘 Если что-то не работает

1. **Убедись, что workspace открыт правильно** — должны быть видны обе папки: `game_engine` и `web_ui`

2. **Проверь, что установлены все зависимости:**
   - Python: `pip install -r requirements.txt` (в папке `game_engine`)
   - Frontend: `npm install` (в папке `web_ui`)

3. **Посмотри в консоль** (внизу в Cursor) — там обычно написано, в чем проблема

4. **Если порты заняты или что-то зависло:**
   - В терминале `web_ui` выполни: `npm run kill`
   - Это убьёт все dev серверы на портах 5500, 3001, 8000

5. **Если изменения в Python коде не применяются:**
   - Python кэширует код! Нужно удалить папку `__pycache__`
   - Открой терминал в `game_engine` и выполни: 
     ```bash
     Remove-Item -Recurse -Force __pycache__
     ```
   - Затем перезапусти Python сервер (`Shift+F5` → `F5`)

6. **Если браузер не подключается к серверу:**
   - Проверь, что frontend сервер запущен (должен быть терминал с `npm run dev`)
   - Проверь, что Python сервер запущен (должно быть сообщение "Server starting at ws://localhost:8000")
   - Попробуй обновить страницу в браузере (`F5`)

7. **Если frontend не запускается:**
   - Убедись, что Node.js установлен: `node --version`
   - Попробуй переустановить зависимости: `npm install`

8. Если совсем застряла — не стесняйся спросить! 😊
